# VTBL.Restrict

UI для работы с **рестриктивными списками** (МВК, Террористы и др.): загрузка Excel/CSV на удалённую папку **as is** (без разбора содержимого), уведомление сервиса парсинга через RabbitMQ, ручная обработка особых случаев по ссылке из письма с данными из БД.

Парсинг и интерпретация содержимого файлов в этом сервисе **не выполняются**.

## Структура

| Элемент | Описание |
| --- | --- |
| `VTBL.Restrict.sln` | Solution Visual Studio |
| `VTBL.Restrict.UI` | Веб-приложение (Razor Pages, `.NET 5.0`) |
| `docs/` | Проектная документация (ТЗ, БД, интеграции, экраны, архитектура) |

См. [docs/README.md](docs/README.md).
