# Каталог: VTBL.Restrict.Loader.Context

## Назначение
EF Core контекст и реализации портов Application для SQL (RestrictDb).

## Файлы

### RestrictDbContext.cs
**Классы:**
- `RestrictDbContext` — DbContext схемы `restrict`
  - DbSet: `ListTypes`, `UploadBatches`, `RcListEntries`

### DependencyInjection.cs
**Классы:**
- `DependencyInjection` — extension `AddRestrictContext`
  - Регистрирует `RestrictDbContext`, `IListTypeReadStore` → Ef, `IUploadBatchStore` → Ef

### Entities/ListTypeEntity.cs
**Классы:**
- `ListTypeEntity` — справочник типов списка; navigation `UploadBatches`

### Entities/UploadBatchEntity.cs
**Классы:**
- `UploadBatchEntity` — учёт загрузок и статуса notify

### Entities/RcListEntryEntity.cs
**Классы:**
- `RcListEntryEntity` — записи RC-листа

### Stores/EfListTypeReadStore.cs
**Классы:**
- `EfListTypeReadStore` — чтение ListType из SQL

### Stores/EfUploadBatchStore.cs
**Классы:**
- `EfUploadBatchStore` — CRUD UploadBatch в SQL

## Зависимости
- `VTBL.Restrict.Loader.Application` — порты `IListTypeReadStore`, `IUploadBatchStore`
