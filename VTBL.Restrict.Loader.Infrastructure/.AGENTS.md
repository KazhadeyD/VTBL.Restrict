# Каталог: VTBL.Restrict.Loader.Infrastructure

## Назначение
Инфраструктурные реализации: FileShare, path builder, RabbitMQ/InMemory notifier, InMemory stores, composition root DI.

## Файлы

### DependencyInjection.cs
**Классы:**
- `DependencyInjection` — extension `AddRestrictInfrastructure`
  - ListType/Batch: EF при `ConnectionStrings:RestrictDb`, иначе InMemory
  - Notifier: RabbitMQ при Host, иначе InMemory
  - Transient: `UploadRestrictFileCommand`, `RetryUploadNotificationCommand`

### Stub/InMemoryListTypeReadStore.cs
**Классы:**
- `InMemoryListTypeReadStore` — справочник ListType в памяти

### Stub/InMemoryUploadBatchStore.cs
**Классы:**
- `InMemoryUploadBatchStore` — UploadBatch в памяти

### Files/UploadPathBuilder.cs / PathBuilder.cs / UncFileShareStore.cs
**Классы:**
- Построение пути и запись файла as-is на UNC/локальную шару

### Messaging/RabbitMqUploadNotifier.cs / Stub/InMemoryUploadNotifier.cs
**Классы:**
- Публикация RestrictFileUploaded / no-op для тестов

## Зависимости
- `VTBL.Restrict.Loader.Application` — порты и Upload commands
- `VTBL.Restrict.Loader.Context` — EF при непустом RestrictDb
